# Fitness Blog

A self-hosted fitness tracking website powered by GitHub Pages.

The repository itself is the database.

Every workout is stored in Git.

## Features

* Workout Log
* Body Weight
* Personal Records
* Statistics
* Charts
* Git History
* GitHub Pages

## Technology

* Jekyll
* GitHub Pages
* Chart.js
* YAML
* GitHub Actions

## Quick Start

``` shell

git clone

bundle install

bundle exec jekyll serve

```

## Folder Structure

* _data
* assets
* _layouts
* _includes
* .github

## Update Workout

``` shell
git add .

git commit -m "Workout"

git push

```
